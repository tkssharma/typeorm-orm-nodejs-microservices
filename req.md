## Prerequisites & Setup Instructions

Before starting this course, please make sure the following tools are installed and ready on your system.

---

### 1. Node.js (LTS Version)

This course uses **Node.js (LTS)** for building backend applications.

**Requirements**

- Basic understanding of JavaScript
- Node.js version **18+ (LTS recommended)**

**Verify Installation**

```bash
node -v
npm -v
```

---

### 2. NVM (Node Version Manager)

We use **NVM** to manage multiple Node.js versions easily.

**Why NVM?**

- Switch Node versions per project
- Avoid global version conflicts
- Industry best practice

**Verify Installation**

```bash
nvm --version
```

---

### 3. Docker

Docker is used to run databases and services in isolated containers.

**Why Docker?**

- No need to install databases locally
- Consistent development environment
- Used in real-world production workflows

**Verify Installation**

```bash
docker --version
docker compose version
```

> Make sure Docker Desktop is running before starting the course.

---

### 4. TablePlus

TablePlus is a GUI tool to view and manage databases.

**Used For**

- Viewing database tables
- Running queries
- Debugging data issues

**Supported Databases**

- PostgreSQL
- MySQL
- MongoDB
- DynamoDB (via plugins)

---

### 5. Visual Studio Code (VS Code)

VS Code is the recommended code editor for this course.

**Recommended Extensions**

- ESLint
- Prettier
- Docker
- Prisma (if applicable)
- GitLens

---
